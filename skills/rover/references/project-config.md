# Rover Project Configuration

Rover supports per-project configuration through a `rover.yaml` manifest and a `plugin-versions.lock` lockfile. These files live in a `.rover/` directory at the project root.

## rover.yaml

The project manifest declares plugin versions and project-level settings.

```yaml
# .rover/rover.yaml
plugins:
  router: "=1.57.1"
  supergraph: "=2.9.3"
  apollo-mcp-server: "=0.3.0"

settings:
  allow_automatic_download: true
```

### Plugin Versions

The `plugins:` section declares which versions of each supported plugin to use for this project:

| Plugin | Description |
|--------|-------------|
| `router` | Apollo Router binary for `rover dev` |
| `supergraph` | Composition plugin for `rover supergraph compose` and `rover dev` |
| `apollo-mcp-server` | MCP server plugin for `rover dev --mcp` |

Version formats follow the same conventions as `rover plugin install`:

| Format | Meaning |
|--------|---------|
| `=1.57.1` | Exact version |
| `1` | Latest 1.x release |
| `latest-2` | Latest 2.x release |

### Settings

The `settings:` section configures project-level behavior:

| Setting | Description |
|---------|-------------|
| `allow_automatic_download` | Whether Rover can automatically download plugins (`true`/`false`). Overridable with `APOLLO_ROVER_ALLOW_AUTOMATIC_DOWNLOAD` env var |

Unknown top-level keys in `rover.yaml` are ignored for forward compatibility. Unknown keys under `plugins:` are errors.

## plugin-versions.lock

The lockfile records exact installed plugin versions. Rover writes this file automatically when installing plugins. Commit it to version control for reproducible builds.

```toml
# .rover/plugin-versions.lock
# This file is auto-generated by Rover. Do not edit manually.

[plugins]
router = "1.57.1"
supergraph = "2.9.3"
```

## Project-Level vs Global Installs

Plugins can be installed at two levels:

| Level | Location | Use case |
|-------|----------|----------|
| Project | `.rover/bin/` beside the manifest | Reproducible builds, per-project versions |
| Global | `~/.rover/bin/` | Shared across all projects |

```bash
# Install into the current project (default)
rover plugin install router@=1.57.1

# Install globally
rover plugin install router@=1.57.1 --global

# Install into a specific project
rover plugin install router@=1.57.1 --manifest-path ./my-project/.rover/rover.yaml

# Install all plugins declared in the project manifest
rover plugin install

# Use only already-installed plugins (never download)
rover plugin install --no-download
```

### Resolution Order

When Rover needs a plugin, it looks in this order:

1. Project-level install (`.rover/bin/` found by searching up from the working directory)
2. Global install (`~/.rover/bin/`)

Use `--global` or `APOLLO_ROVER_GLOBAL` to force global resolution.

## Related Environment Variables

| Variable | Description |
|----------|-------------|
| `APOLLO_ROVER_GLOBAL` | Target the global install root (`true`/`1`) |
| `APOLLO_ROVER_NO_DOWNLOAD` | Never download plugins |
| `APOLLO_ROVER_ALLOW_AUTOMATIC_DOWNLOAD` | Allow or block automatic downloads |

## Error Codes

| Code | Description |
|------|-------------|
| E058 | Plugin not installed and automatic downloads are blocked |
| E060 | Credentials cannot be stored in `rover.yaml` |
| E061 | Duplicate settings in `rover.yaml` |
